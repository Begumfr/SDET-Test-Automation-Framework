##  Overview

This project is a Test Automation Framework built using Java, Selenium WebDriver, Cucumber (BDD), and TestNG.

The framework follows the Page Object Model (POM) design pattern and includes reusable utilities for scalable and maintainable automation testing.

---

##  Framework Design

- Page Object Model (POM)
- Cucumber BDD Structure
- TestNG Runner Configuration
- Reusable Utility Classes
- Configuration Management
- Explicit Wait Strategy
- Cross Browser Support (if configured)
